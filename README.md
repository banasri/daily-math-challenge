# Daily Math Challenge (DMC)

A React + Firebase web app that delivers one math puzzle per day to students.

## Features

- Google authentication
- Daily MCQ based on grade
- Answer submission with feedback
- Public leaderboard
- 14-day free trial + subscription model
- Admin question management via Firestore

## Tech Stack

- React (Vite)
- Firebase Auth
- Firestore
- CSS

## Setup

```bash
npm install
npm run dev
```
